# Catholic Near Me

Ứng dụng web tìm nhà thờ Công giáo gần bạn trên bản đồ OpenStreetMap, kèm chatbot hỏi đáp giờ lễ.
Mã nguồn, hướng dẫn cài đặt và cách chạy nằm trong [chatbot/README.md](chatbot/README.md).

Thư mục gốc còn lưu dữ liệu (`data/`), các script thu thập dữ liệu và một frontend thử nghiệm cũ dùng Overpass
(`index.html`, `js/`, `css/`). Ứng dụng mới không dùng đến các file này.
